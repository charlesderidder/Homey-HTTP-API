A controlled interface for Homey

Homey Toolkit combines a local HTTP API with configurable countdown timers for Homey flows. Timers can be started, adjusted, paused, resumed, stopped, and used as flow triggers and conditions.

The HTTP API provides a controlled bridge that allows external signals, scripts, and services to interact with the smart home. Countdown timers add a reusable way to drive delayed automations, including restartable and random-duration timers.

Use the API locally. Keep the boundary strict: it is a bridge inside the network, not an open door to the internet.
